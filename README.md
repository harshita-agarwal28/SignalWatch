# SignalWatch

SignalWatch is a smart market watchlist UI focused on meaningful change rather
than a dense quote table. It includes a return briefing, expandable evidence
cards, animated market radar, watchlist sparklines, filters, and an add-company
flow.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
```

The GitHub Pages workflow deploys the production build from `main` to:
`https://harshita-agarwal28.github.io/SignalWatch/`
